# Assets

This directory contains optional reusable visual assets and icon references.

## Purpose

Optional reference assets that can be used when implementing the AetherLearn design system.

## Contents

- **icons/** — Icon SVG files following the AetherLearn icon style
- **logos/** — Brand mark variations
- **patterns/** — Reusable visual patterns

## Icon Style

AetherLearn uses Lucide React icons with:
- Stroke-based icons
- Stroke width: 1.5-2px
- Rounded line caps
- Standard sizes: h-4 w-4, h-5 w-5, h-6 w-6

## Note

Assets are optional. The design system is fully functional without them.
