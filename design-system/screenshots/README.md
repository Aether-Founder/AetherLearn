# Screenshots

This directory contains visual source material organized by viewport and state.

## Organization

- **desktop/** — Desktop viewport screenshots
- **tablet/** — Tablet viewport screenshots
- **mobile/** — Mobile viewport screenshots
- **states/** — Interactive state screenshots (hover, focus, active, etc.)

## Purpose

Screenshots provide visual references for:
- Component appearance
- Responsive behavior
- State variations
- Layout patterns

## Usage

Use screenshots as visual reference when implementing components. Always refer to DESIGN.md for authoritative specifications.
