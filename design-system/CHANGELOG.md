# Changelog

All notable changes to the AetherLearn Design System will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-08

### Major
- Initial release of AetherLearn Design System
- Complete visual design specification (DESIGN.md)
- Application workflow documentation (SKILL.md)
- Machine-readable design tokens (tokens/tokens.json)
- Component and state atlas (references/component-atlas.md)
- Detailed reference documentation (references/)
- Design review procedure (references/design-review.md)
- Canonical-source audit
- Shared design-system standard compliance

### Minor
- Component reference for chip/button, search field, flashcard, button, card, dropdown, skeleton, stat display, input
- Motion specification with durations, easing, animations
- Responsive behavior documentation
- Accessibility conventions
- Library policy and approvals
- UI patterns documentation
- Implementation notes from codebase

### Patch
- None

## Version Update Guidelines

### Major
Changes that significantly alter the design language or create breaking visual-system changes:
- New color palette
- New typography system
- New component paradigm
- Breaking changes to tokens
- Removal of documented patterns

### Minor
New reusable patterns, new components, or additive design-system capabilities:
- New component documented
- New pattern documented
- New token added
- New library approved
- Documentation improvements

### Patch
Corrections, documentation improvements, clarifications, or small token corrections:
- Typo fixes
- Clarification of existing rules
- Small token value corrections
- Implementation note additions
- Changelog formatting
