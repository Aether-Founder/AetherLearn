Aether Banner Demo

This is a demo page showing the Aether attribution banner in action.

How to Use

To add the Aether banner to any HTML page, simply add this script tag before the closing </body> tag:

<script src="https://your-domain.com/aether-banner.js"></script>

Features:

  • ✅ Non-removable banner
  • ✅ Fixed position (bottom-right)
  • ✅ Maximum z-index to stay on top
  • ✅ Anti-removal protection
  • ✅ Links to Aether website
  • ✅ Responsive design
  • ✅ Modern glassmorphism effect

Configuration:

The banner can be customized by modifying the CONFIG object in the JavaScript file:

  • Brand name and logo
  • Colors and styling
  • Position
  • Size
