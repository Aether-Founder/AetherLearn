How to Use

To add the theme picker to any HTML page, simply add this script tag before the closing </body> tag:

<script src="https://your-domain.com/aether-theme-picker.js"></script>

Configuration

You can customize the theme picker by modifying the CONFIG object in the JavaScript file:

const CONFIG = {
    storageKey: 'aether-selected-theme',
    position: 'top-right', // top-right, top-left, bottom-right, bottom-left
    zIndex: '2147483646',
    showThemePicker: true,
    defaultTheme: 'aether',
};

API Usage

You can also control the theme picker programmatically:

// Set theme by ID (preview only)
AetherThemePicker.setTheme('dracula');

// Save the current preview theme
AetherThemePicker.saveTheme();

// Get current saved theme
const currentTheme = AetherThemePicker.getCurrentTheme();

// Get current preview theme
const previewTheme = AetherThemePicker.getPreviewTheme();

Theme Categories

The theme picker includes themes from various categories:

  • Dark themes (Dracula, Monokai, Nord, etc.)
  • Light themes (Solarized Light, Gruvbox Light, etc.)
  • Colorful themes (Miami, Vaporwave, Aurora, etc.)
  • Minimal themes (Paper, Dots, Shadow, etc.)
  • Retro themes (80s After Dark, SNES, DMG, etc.)
  • And many more!

Note: Each theme is a standalone color palette. Click on a theme to preview it, then click "Opslaan" to confirm your selection.
